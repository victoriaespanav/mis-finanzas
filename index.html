Reservas automáticas

La reserva se crea en la cuenta donde recibes el reembolso, se traslada al transferir dinero y se libera al pagar la tarjeta desde esa cuenta. Si editas o eliminas un movimiento, se recalcula. Las reservas manuales se mantienen independientes.

Respaldo y recuperación

Tus datos se guardan en este navegador. Exporta un JSON antes de cambiar de versión o dispositivo. La importación muestra una confirmación antes de reemplazar datos.

Notas

Las reservas no son gastos. El valor real de las cuotas puede incluir intereses y comisiones. Los pagos de tarjetas no se cuentan como nuevo consumo. Los importes de facturación son estimaciones hasta conciliarlos con el banco. No se conecta a entidades financieras.
